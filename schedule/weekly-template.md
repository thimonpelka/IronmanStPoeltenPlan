## Daily Breakdown

_Structure below is effective **2026-W37** (week of Sep 7). Reorganized 2026-08-24 (see the
change note at the bottom): 3rd bike (Tue easy) + 3rd run (Fri easy) added; swim moved
Tue→Mon; upper-body gym moved Mon→Thu. Weeks W33–W36 were already written and keep their
older layout._

### Monday
- **Work**: ~08:00–16:30 (flexible start, can begin at 09:00)
- **Evening — Easy swim** (one of the 3×/week). Light day after Sunday's long run; the swim
  is the flexible one of the three. (This is the swim moved off Tuesday.)

### Tuesday
- **Work**: ~08:00–16:30 (flexible start, can begin at 09:00)
- **Morning** (~06:30–08:00) — Run (Pinned slot: the quality run — tempo/threshold, ≤1h)
- **Afternoon — Easy ride (~1h, Z2 aerobic)** — the 3rd weekly bike. Keep it genuinely easy;
  it flushes the legs after the morning quality run and adds aerobic volume, not stress.
  Afternoon, so the no-weekday-AM-outdoor constraint doesn't apply. First cut if load runs high.

### Wednesday
- **Work**: ~08:00–12:30 (flexible start)
- **06:30** — Gym — **Lower body + posterior chain, primary strength day** (~60min), before
  work. ~30h before Thursday's ride. Pinned.
- **Evening** — Swim (one of the 3×/week swims)

### Thursday
- **Midday/afternoon** — Mid-week quality bike (sweet-spot/threshold intervals; grows in
  duration on this open day). Legs recovered from Wednesday's lower gym (~30h).
- **Afternoon (after the bike)** — Gym — Upper + core + hip/ankle stability (~55min). Low
  leg load, so it doesn't touch the intervals. (Moved here from Monday.)

### Friday
- No fixed commitments
- **Easy/OW swim** — in OW season (Aug–Oct) this is the open-water swim.
- **3rd run — easy and short (30–45min, Z1–low Z2).** Base-building aerobic volume, kept
  gentle to protect the weekend block. **Skipped in brick weeks** (the Saturday brick already
  carries a run, keeping the week at max 3 runs). Second cut if load runs high (after the Tue ride).

### Saturday
- No fixed commitments
- **Morning** — Long Ride (Pinned)
- Occasional Brick Session (ride + short run) replaces standard long ride — on these weeks,
  drop the Friday run.

### Sunday
- No fixed commitments
- **Morning** — Long Run (Pinned)

## Standing Session Summary

| Day | Pinned Session(s) | Type |
|-----|---------------|------|
| Mon | Easy swim | Recovery (light) — 1 of 3× swim |
| Tue | Run (AM, quality) + Easy ride (PM) | Quality run + 3rd bike (easy) |
| Wed | Lower gym (06:30) + Swim (eve) | Primary strength + 1 of 3× swim |
| Thu | Quality bike (intervals) + Upper gym (after) | Sweet-spot/threshold + strength |
| Fri | Easy/OW swim + Easy run | 1 of 3× swim + 3rd run (skip in brick weeks) |
| Sat | Long Ride (or Brick) | Endurance |
| Sun | Long Run | Endurance |

Weekly totals: **swim 3× (Mon/Wed/Fri), bike 3× (Tue/Thu/Sat), run 3× (Tue/Fri/Sun), gym 2×
(Wed/Thu)**. The Tuesday ride and Friday run are deliberately *easy* aerobic-volume additions —
keep them gentle. If load runs high (poor sleep/legs/HRV), cut order is: **Friday run first,
then the Tuesday ride.** In brick weeks the Friday run drops automatically (max 3 runs/week).
