# Week 2026-W43 (Oct 19–25) — Build Phase 1, Week 3 (peak of the triple)

## Context

**Top of the first Build 1 loading triple (W41→W43) before the W44 deload.** Highest load of
the block: the **second bike VO2** of the every-other-week cadence, a brick, and the longest
sessions before the deload. Push the quality, then W44 absorbs it (and carries the clean FTP
retest). If sleep/legs/HRV are off this week, cut the Friday run first, then the Tuesday ride —
don't grind a hole right before the deload.

Brick week again (Sat) → **Friday run drops**.

**⚠️ FTP still 238W** — clean retest next week (W44). Prescribe to the bands below; the W44
retest resets them.

- Bike: Z2 = **132–179W** · Sweet-spot = **209–224W** · VO2 = **250–270W**
- Run: Z2 = **135–155 bpm** · Z3 tempo = **156–168 bpm** · Z5 = **179+ bpm** (<4:15/km)

### Tue Oct 21
**Morning — Run, quality (threshold)** (~60min)

Warm up 15min. **2 × 15min @ Z3 tempo/threshold** (upper Z3, 164–168 bpm), 3min easy between.
**4 × 20s strides.** Cool down. _No run VO2 this week — the VO2 dose is on the **bike** Thursday
(4×4min), and the run VO2 was W42. Clean threshold here keeps the two VO2 sessions from
stacking in one week._

**Afternoon — Easy ride** (~60min) — Z2, genuinely easy. Flush + volume.

---

### Wed Oct 22
**06:30 — Gym — Lower body, Build** (~55min) — squat 4 × 4, RDL, split squat, calf, core.
Peak-of-block load, but keep 2 reps in reserve — the bike VO2 is tomorrow. See `plans/strength.md`.

**Evening — Swim, aerobic / CSS-pace** (~55min, ~2200m) — the quality swim.

- Warm-up: 300m · Drills: 6 × 50m
- **Main set: 10 × 150m @ CSS pace**, 20s rest — hold the pace from the first rep to the last.
- 4 × 50m building to fast, 20s rest
- Cool-down: 200m

---

### Thu Oct 23
**Midday/afternoon — Bike VO2** (~95min) — *the key session; protect it*

Warm up 20min Z2 with openers. Then **4 × 4min @ VO2 (250–265W, ~105–111% FTP)**, 4min easy
between (full recovery). Longer reps than W41's 5×3min = a bigger VO2 stimulus. Cool down 15min.
Hold even watts; if rep 4 sags below 245W, that's the ceiling — note it (it feeds the W44 FTP
read). **Trainer** for steady control.

**Afternoon (after the ride) — Gym — Upper + core** (~50min) — push/pull/overhead + core/stability.

---

_No Friday run — brick week (Saturday carries the transition run)._

### Sat Oct 25
**BRICK — Long Ride + transition run** — Z2 ride, **~2.5–2.75h, ~80–95km**, real elevation

The last big session before the deload — make the ride count on climbing, then run the legs in

### Sun Oct 26
