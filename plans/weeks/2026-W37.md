# Week 2026-W37 (Sep 7–13) — Base Phase, Week 13

## Context

**First week of the new 3-swim / 3-bike / 3-run structure** (reorganized 2026-08-24, see
`schedule/weekly-template.md`) and the start of the final base block (W37–W38; W39 is the
volleyball camp). Fresh off the W36 deload + tests, so it's a good spot to introduce the two
new *easy* sessions — the **Tue afternoon easy ride** and the **Fri easy run** — without
piling stress on. Gym also shifts: **legs → Wed 06:30 (primary), upper → Thu afternoon after
the bike.**

Two things to watch this week:
1. **The new easy sessions must stay genuinely easy.** They add aerobic volume, not stress.
   Tue ride RPE low, Fri run recovery pace. If sleep/legs are off, cut the Fri run first.
2. **Prioritize an open-water swim Friday while the season lasts** — OW block 1 is behind
   (only Jul 27 so far; Aug OW sessions became pool swims). Vienna OW closes ~Oct and the
   camp costs a week, so W37–38 Fridays are the window.

**⚠️ Zones — check against the Sep 5 FTP retest.** Values below assume **FTP 238W**. If the
retest changed it, recompute **sweet-spot = 88–94% of the new FTP** and adjust the ride
targets. If the optional Sep 1 run threshold effort happened, update the run pace bands too.

- Bike (FTP 238W): Z2 = **132–179W** · Sweet-spot = **209–224W** (88–94%)
- Run (HRmax 192 / LTHR ~178): Z2 = **135–155 bpm** (~5:00–5:45/km) · Z3 tempo = **156–168 bpm** (~4:35–5:00/km)

## Schedule

### Mon Sep 7
**Evening — Swim (easy/technique)** (~45–50min, ~1500–1800m)

Light day after Sunday's long run. Warm-up, technique drills, a few continuous 200–300s at
easy rhythm, cool-down. Keep it relaxed — this is the recovery swim of the three.

---

### Tue Sep 8
**Morning — Run, quality (tempo)** (~60min)

Warm up 15min. Then **3 × 10min @ Z3 tempo** (156–168 bpm, ~4:35–5:00/km), 3min easy jog
between. **4 × 20s strides.** Cool down 10min.

**Afternoon — Easy ride (NEW, ~60min)** — Z2 (132–179W), flat/rolling, **genuinely easy**
(RPE 3–4). This is aerobic volume + leg flush after the morning run, not a workout. Don't
let it drift into Z3.

---

### Wed Sep 9
**06:30 — Gym — Lower body, HEAVY** (~60min)

Base strength block continues: squat **4 × 5–6**, RDL 3 × 6, Bulgarian split squat 3 × 8/leg,
calf 3 × 12, Pallof 3 × 10/side. 1–2 reps in reserve; progress load only if all reps clean.
~30h before Thursday's ride — some heaviness in the legs is fine. See `plans/strength.md`.

**Evening — Swim (pool)** (~45min, ~1300m) — drills + rhythm, technique focus.

---

### Thu Sep 10
**Midday/afternoon — Mid-week ride, sweet-spot** (~100–110min) — *protect this session*

Warm up 15min Z2. Then **3 × 15min @ sweet-spot (209–224W)**, 5min easy between. Cool down
15min. Progression on W34's 3×12. Hold the band steady; if watts sag in the third rep,
that's the ceiling for now — note it. Ride outdoors long if you like, with the intervals
inside a longer Z2 ride.

**Afternoon (after the ride) — Gym — Upper + core** (~55min) — first time in the new Thursday
slot. Push/pull/overhead + core + hip/ankle stability. Low leg load, so it doesn't touch the
ride. See `plans/strength.md`.

---

### Fri Sep 11
**Open Water Swim** (~35–45min) — OW block 1, priority while the season lasts.

Sighting every 6–8 strokes, straight-line segments, calm breathing without a wall. Someone
present; get out if cold. If water/weather genuinely doesn't allow, do a pool swim instead —
but try for OW.

**Easy run (NEW, ~30–35min)** — Z1–low Z2 (HR <145, >5:45/km). Recovery pace, short. This is
the 3rd run — volume, not intensity. **Skip it entirely if the legs are flat** (weekend block
comes next).

---

### Sat Sep 12
**Long Ride** — Z2 endurance, ~3h, ~90–100km, **real elevation (aim 700–1000m)**.

Firmly Z2 on the flats (132–179W, ~150–170W); let watts climb naturally on the hills. Fuel
60–80g carbs/h from 45min; carry sodium. Start earlier if it's warm.

---

### Sun Sep 13
**Long Run** — Z2, ~20–21km, ~1:50h.

Consistent Z2 (135–155 bpm). Optional late-run progression: if it's still easy past 16km,
lift the final 3km to steady Z3 — only if HR has been stable (the Aug 23 HR wobble is a
reminder to bail on the progression if HR looks noisy).
